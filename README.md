# Customer Churn Prediction using Machine Learning

## Project Overview
This project predicts customer churn in a European bank using Machine Learning techniques and provides an interactive Streamlit dashboard for visualization and analysis.

## Objectives
- Predict customer churn
- Analyze customer behavior
- Identify factors influencing churn
- Provide business recommendations

## Tools and Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Matplotlib
- Excel

## Project Files

### Dataset
- European_Bank CSV.csv

### Model Files
- churn_model.pkl
- scaler.pkl

### Application
- app.py

### Reports
- Research Paper
- Executive Summary

## Dashboard Features
- Customer Churn Prediction
- Churn Distribution Analysis
- Geography-wise Churn Analysis
- Gender-wise Churn Analysis

## Key Findings
- Germany showed the highest churn rate.
- Female customers exhibited slightly higher churn rates than male customers.
- Premium active customers maintained higher balances and lower churn rates.
- Active members were less likely to churn.
